# کارهای بزرگ — ورک‌فلو و ساب‌ایجنت (قانون همیشگی)

اگر درخواست جزو «کار بزرگ» شد، **مستقیم کد را شروع نکن**. سیاست کامل: بخش «کارهای بزرگ» در `AGENTS.md` (پیش از شروع بخوان).

## محرک‌ها
- **صریح:** «کار بزرگ»، «کار سنگین»، «تمام»، «کامل»، «هر فایل/ماژول/صفحه»، «کل پروژه»، «خودکار انجامش بده»، «برگردان»، «با ورک‌فلو»، «با ساب‌ایجنت‌ها»، «پارالل»، «پخشش کن»، «ارکسترات کن»
- **خودکار (حداقل ۲):** واحدهای قابل‌شمارش ≥ ۴؛ stageهای ≥ ۲ وابسته به هم؛ جواب = نتایج به‌ازای هر آیتم + ترکیب پایانی؛ لحنِ محدوده‌ی بزرگ
- **دودان** → یک سؤال (با ورک‌فلو / با یک ایجنت / همین‌طور انجامش بده). کار خیلی کوچک → سؤال نپرس.

## پلای‌لاین
1. ابزار `skills` → اسکیل **`auto-big-jobs`** (routing + تجزیه‌ی واحد + توپولوژی A/B/C/D)
2. اگر ورک‌فلو شد → ابزار `skills` → اسکیل **`dynamic-workflows`** (اجرا: ساب‌ایجنت، worktree، gate، گزارش)
3. اگر سشن ابزار ساب‌تسک ندارد → fan-out سریعی با همان انضباط + ذکر صریح در گزارش

## نکات کلیدی این پروژه (جزئیات در `AGENTS.md`)
- واحدها: ۲۱ ماژول api / ۵۷ مدل Prisma / صفحات web / ۹ اندپوینت nlp / بخش‌های `کل طرح.md`
- Gate (فقط سشن اصلی): `pnpm --filter api test` + `pnpm --filter api build` + `pnpm --filter web build` + `python -m py_compile apps/nlp/app/main.py`
- از `pnpm test` ریشه استفاده **نکن** (پکیج web اسکریپت test ندارد)
- e2e: `pnpm --filter api test:e2e` (پیش‌تر `docker compose up -d postgres`)
- round cap = ۳ — مالکیت فایل‌ها بین workerها بی‌اشتراک — گزارش پایانی `WORKFLOW-REPORT.md` (با `verified:` و `notCovered:`)
- متن کاربرمحور فارسی — کار UI با اسکیل `vibefarsi`
